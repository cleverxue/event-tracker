# Backtest Notes — 事件驱动回测规范（实测沉淀）

`scripts/backtest_events.py` 用于验证抽取出的事件标签是否携带前瞻信息，
是 **L2 → L3** 的证据来源。本文件记录首轮真实回测踩到的坑与硬性规范，
后续扩样本时**必须遵守**，否则会得出误导性结论。

---

## 1. 铁律：必须用超额收益（市场中性化）

**永远看超额收益（个股 − 基准），不要看原始收益。**

- 首轮真实回测（45 份 Tier A 公告，2024-09~10 窗口）的**原始收益**显示"利空事件反而上涨"
  —— 完全反直觉。
- 根因：窗口恰好包含 **2024-09-24 政策大反弹**，全市场普涨，个股原始收益被大盘 beta 主导，
  事件信号被淹没。
- 加基准（沪深300 `000300.SH`）做超额后信号翻正：`利空` 事件 **T+1/T+5 跑输大盘占比 71%**。

> 结论：原始收益 = 事件信号 + 市场 beta + 行业 beta。不减掉 beta，测的是大盘不是事件。
> 脚本已默认输出超额收益；原始收益仅写入 CSV `ret_t*` 列供审计，**不作为结论**。

**进一步（L3 建议）**：只减大盘仍残留**行业 beta**与**规模/风格 beta**。理想做法是减
行业指数或做行业内排序，甚至跑 Fama-French / Barra 风格中性化。最低要求是减宽基指数。

## 2. 样本要求（L3 门槛）

首轮 n=35 **仅为方法学演示，不构成证据**。L3 需要：

| 维度 | 首轮（不达标） | L3 要求 |
|---|---|---|
| 样本量 | 35（利好仅 4） | 每个 direction × event_type ≥ 100 |
| 时间跨度 | 单一 2 个月窗口 | 跨 ≥ 3 年、覆盖牛/熊/震荡多种 regime |
| 方向均衡 | 利好只有重组预案 | 利好需含增持/回购/预增等多来源 |
| 事件类型 | 仅 Tier A 3 类 | 覆盖全部 primary 类型 |

单一时间窗 = 单一 regime，任何结论都被那段行情绑架（见第 1 条的 9·24）。

## 3. 已知 confound 清单（扩样本时逐一排查）

- **政策/事件窗**：9·24（2024）、8·24（2015）、熔断（2016-01）等极端窗口，会让任意事件"看起来有效"。
  按 regime 分层统计，不要把不同 regime 混在一起平均。
- **幸存者偏差**：退市/长期停牌股缺价格 → 被静默剔除。脚本对无价数据记 `[warn]` 并跳过，
  统计时应报告被剔除数量，避免"只统计活下来的"。
- **前视偏差**：`ann_date` 是**披露日**，非事项发生日。回测以披露日为 t0 是正确的（信息可得时点），
  但要注意盘后披露的公告，T+1 才是首个可交易日——脚本用"首个 ≥ ann_date 的交易日"对齐，已处理。
- **复权**：新浪 `getKLineData` 返回**不复权**价。短周期（T+1~T+20）内若遇除权除息会有跳空噪声。
  L3 应换前复权价源（或在窗口内剔除除权日样本）。
- **停牌**：t0 或持有期停牌会使收益失真。L3 应剔除持有期含停牌的样本。

## 4. 指标口径

- **超额收益** `exret_h = 个股收益_h − 基准收益_h`，同一 t0、同一持有期对齐。
- **命中率**：`利好跑赢占比` = 利好事件中 `exret > 0` 的比例；`利空跑输占比` = 利空中 `exret < 0` 的比例。
- **利好−利空超额价差**：两组超额收益均值之差；持续为正 = 标签有前瞻区分度。
- 同时看 **均值与中位数**：小样本+尾部事件（诉讼/重组）分布厚尾，中位数更稳健。

## 5. 复现命令

```bash
# 1) 全市场发现事件（跨多年、多类型，避免单一窗口）
python scripts/fetch_announcements.py --keywords 关注函 问询函 诉讼 对外担保 重大资产重组 \
  --start 20220101 --end 20241231 --out cache/
# 2) 抽取 + 校验
python scripts/extract_events.py --cache cache/ --out reports/events/all.csv
python scripts/validate_events.py reports/events/all.csv
# 3) 超额收益回测（默认基准 000300.SH，可换行业指数）
python scripts/backtest_events.py reports/events/all.csv --out reports/bt.csv --benchmark 000300.SH
```

## 6. 定位声明

本回测是**证据**，不是策略：无交易成本、无冲击成本、无仓位管理、无风控。
产出用于"事件标签是否有前瞻信息"的**研究性验证**，不构成任何投资建议。
参见 [[event-taxonomy]] 的分类精度原则与 SKILL.md 的免责契约。
