# L3 Evidence — 2022–2024 事件驱动回测结果

首个正式 L3 证据运行，遵循 [[backtest-notes]] 的规范（跨年多 regime、方向均衡、
市场中性化）。结论：**抽取器的 `利空` 方向标签、尤其 `监管问询(regulatory_inquiry)`
携带真实的市场相对预测信号；`利好` 标签则基本无预测力（利好已被 price-in）。**

## 运行参数

| 项 | 值 |
|---|---|
| 样本期 | 2022-01-01 ~ 2024-12-31（12 个季度，逐季采样避免时间集中） |
| 发现方式 | `fetch_announcements.py --keywords`（12 个方向均衡关键词）全市场搜索，`--no-text` 仅取标题 |
| 公告数 | 7,423（已过滤 HK/B 股，仅保留沪深 6 位 A 股代码） |
| 事件数 | **4,248**（`extract_events.py` 纯标题分类，validate OK） |
| 方向分布 | 利空 2,449 / 利好 1,763 / 中性 36 |
| 类型分布 | holding_change 1067、regulatory 1014、earnings 633、restructuring 560、litigation 552、governance 409、pledge 13 |
| 基准 | 沪深300（000300.SH），超额收益 = 个股 − 基准 |
| 有效样本覆盖 | T+20 **98.8%**（停牌/退市/新上市剔除仅约 1%，幸存者偏差有限） |

## 主结果：超额收益信号检验

| 横截面 | T+1 | T+5 | T+10 | T+20 |
|---|---|---|---|---|
| 利空跑输大盘占比 | 53.8% | **57.6%** | **56.6%** | 52.0% |
| 利好跑赢大盘占比 | 47.7% | 44.1% | 44.7% | 50.3% |
| 利好−利空 超额价差 | +0.26% | +0.66% | +1.11% | **+1.88%** |

- **利空标签有效**：跑输占比稳定 >52%（优于抛硬币 50%），T+5/T+10 达 ~57%；均值超额 T+5=−1.19%、T+10=−1.13%。
- **利好标签无效**：跑赢占比仅 44–50%，T+5/T+10 甚至 <50%；均值超额近 0。→ 利好消息基本已被 price-in（"买预期卖事实"）。
- **价差右向且随持有期放大**（+0.26%→+1.88%），说明标签排序正确，但价差主要由**利空的负超额**贡献，而非利好的正超额。

## 最强信号：监管问询（regulatory_inquiry，n≈1000）

按事件类型看，`regulatory_inquiry` 是唯一在所有持有期都稳定为负、且量大的类型：

| T+1 | T+5 | T+10 | T+20 |
|---|---|---|---|
| −0.60% | −1.98% | **−2.11%** | −1.89% |

**跨 regime 稳健**（T+10 超额，逐年）：

| 年份 | n | 均值超额 | 跑输占比 |
|---|---|---|---|
| 2022（熊） | 330 | −1.35% | 54% |
| 2023（震荡） | 353 | −0.90% | 55% |
| 2024（先跌后涨） | 314 | −4.26% | 64% |

三年全负、跑输占比稳定 54–64%。这是最接近可用 alpha 的发现：**收到问询/关注/监管函 → 后续 ~10 交易日显著跑输大盘约 2%。**

其余类型（holding_change / earnings_preview / restructuring / litigation）超额均接近 0 或噪声级，无稳定信号。

## 诚实的局限

- **利好侧弱**：利好样本主要来自增持/回购/预增/重组预案，均无稳定正超额；不能用作做多信号。
- **仅减大盘 beta**：未做行业/风格中性化，`regulatory_inquiry` 的负超额可能部分来自其在小盘/绩差股的聚集（问询函多发于问题公司）。下一步应做行业内排序或 Barra 风格中性化确认。
- **不复权价**：短周期除权除息噪声；退市股被剔除（覆盖 99%，影响有限但方向上会低估利空的负超额）。
- **无成本**：未计交易/冲击成本，是研究性证据非可交易策略。

## 附：控制权变更（suspension）单独回测 —— 彩票分布

对 `suspension/控制权变更` 单独取样回测（2022–2024，n=605，t0 对齐**复牌后首个交易日**，
覆盖 99.7%）：

| T+20 超额 | 值 |
|---|---|
| 均值 | +0.60%（勉强为正） |
| **中位数** | **−1.32%** |
| **跑赢大盘占比** | **44%**（<50%） |
| 右尾 | >+20% 占 7.8%、>+50% 占 1.5%、max **+138%** |
| 左尾 | <−20% 占 3.6% |
| 逐年中位数 | 2022 −1.9% / 2023 −0.4% / 2024 −1.8%（三年全负，稳健） |

**结论：控制权变更是正偏度"彩票"，不是可靠做多信号。** ~56% 个股跑输大盘，均值仅靠
少数借壳大牛拉正。**edge 全在右尾**——单只买入负期望（中位），只有分散成篮子才可能捕获尾部。
因此 taxonomy 已将其方向从"利好"改为 **`中性`**（severity 高，标记高波动/重大）。

> 教训：经验直觉（易主=利好）被数据推翻。这正是回测的价值——用证据校准标签，而非拍脑袋。

## 结论与下一步

- ✅ **达到 L3**：大样本（n=4248）、跨 3 年多 regime、市场中性化、方向均衡、99% 覆盖。
- 核心可交易线索：**`regulatory_inquiry` 利空信号**（T+10 约 −2% 超额，regime 稳健）。
- 升级路径：行业/风格中性化 → 确认 regulatory 信号非小盘 beta；对利空类做分事件细分（立案 vs 问询函）看强度梯度。

> 本结果基于公开披露与规则化抽取生成，仅供研究参考，不构成任何投资建议。参见 [[backtest-notes]]。
